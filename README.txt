Клодд — локальное распознавание голосовых сообщений

Содержимое:
- Dockerfile — собирает whisper.cpp v1.9.5 и включает мультиязычную tiny-q5_1 модель.
- bridge.py — скачивает Telegram voice, запускает локальную транскрипцию и передаёт текст в обычный маршрут AI/Codex.
- assistant/stt.py — локальный вызов ffmpeg и whisper-cli без Python STT-зависимостей.
- assistant/storage.py — кеш транскрипции в JSONB inbox с проверкой claim_token и generation.
- tests/* — тесты распознавания, кеша, ошибок и регрессий.

Тарифы и API распознавания не используются. Модель включается в Docker-образ во время сборки.
Ограничения: voice-сообщения до 20 MiB и 5 минут; обрабатывается Telegram message.voice, не обычные аудиофайлы message.audio.

Перед установкой проверьте git status --short --branch и сохраните любые локальные изменения.
Файлы в архиве предназначены для замены одноимённых файлов в корне проекта; новые файлы добавляются.
requirements.txt и миграции БД не меняются.

Проверки в подготовленной копии: python -m compileall -q bridge.py assistant tests; python -m pytest -q.
Сборка Docker здесь не проверялась: Docker CLI в среде подготовки отсутствует.
